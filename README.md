── PROJECT 1: YOLO PDF ──────────────────────────────

Tagline: "The PDF tool you actually enjoy using."

Short Description:
YOLO PDF is a premium, AI-powered PDF productivity platform built with Flutter. It brings together all essential PDF operations — merge, split, compress, convert, and OCR — into one beautifully designed, lightning-fast app.

Full Description:
YOLO PDF was born from a simple frustration: existing PDF tools are ugly, slow, and scattered. I set out to build one unified platform that handles every PDF task with a premium experience.

Built with Flutter for seamless cross-platform performance, YOLO PDF features a modern UI with smooth transitions, a dark/light theme system, and an intuitive workflow that makes complex PDF operations feel effortless. The OCR engine can extract text from scanned documents with high accuracy, opening up workflows for digitizing physical documents.

Key Features:
• PDF Merge — Combine multiple PDFs into one with drag-and-drop ordering
• PDF Split — Extract specific pages or ranges with precision
• PDF Compress — Reduce file size without sacrificing quality
• PDF Convert — Convert to and from multiple formats
• OCR (Optical Character Recognition) — Extract text from scanned PDFs
• Modern UI — Glassmorphism design, smooth animations, intuitive UX

Tech: Flutter · Dart · Firebase · PDF libraries · OCR engine

── PROJECT 2: COLLEGE MANAGEMENT APP ───────────────

Tagline: "One platform for every stakeholder in academic life."

Short Description:
A comprehensive college management system built with Flutter and Firebase, featuring dedicated portals for students and faculty, real-time attendance tracking, timetable management, and role-based access control.

Full Description:
Managing a college involves dozens of interconnected workflows — attendance, timetables, notifications, grade tracking, and more. This app brings all of them together in one unified platform.

Built with Flutter for a consistent cross-platform experience and Firebase for real-time sync, the system provides separate, role-secured portals for Students and Faculty. Administrators can configure roles, manage records, and push announcements — all in real time.

Key Features:
• Student Portal — Academic dashboard, attendance view, timetable, notifications
• Faculty Portal — Class management, attendance marking, schedule view
• Real-time Attendance System — Mark and track attendance with instant sync
• Timetable Management — Visual, interactive timetable for all classes
• Role-Based Access Control — Strict permission system for Admin/Faculty/Student
• Push Notifications — Real-time alerts for announcements, schedule changes

Tech: Flutter · Dart · Firebase Auth · Cloud Firestore · Firebase Cloud Messaging

── PROJECT 3: SMART HOME AUTOMATION SYSTEM ─────────

Tagline: "Your home, intelligent and in your control."

Short Description:
An IoT home automation system featuring ESP32-based hardware control, relay switching, voice assistant integration, and a Flutter mobile app — making any home smart, affordable, and responsive.

Full Description:
This project bridges mobile software and real-world hardware to create a fully functional smart home automation system. The ESP32 microcontroller acts as the IoT brain, controlling appliances via relay modules. Sinric Pro enables voice assistant integration with Alexa and Google Home.

The Flutter mobile app provides a clean, intuitive control panel — toggle switches, real-time status indicators, scheduling, and automation rules. The system is designed to be affordable, extensible, and easy to deploy.

Key Features:
• IoT Device Control — ESP32-powered relay control for home appliances
• Mobile App Interface — Flutter app for real-time remote control
• Voice Assistant Support — Works with Amazon Alexa & Google Assistant via Sinric Pro
• Real-time Status — Live device status monitoring in the mobile app
• Scheduling & Automation — Set timers and automation rules
• WiFi-Based Communication — No hub required, direct WiFi control

Tech: Flutter · Python · ESP32 · Arduino · Sinric Pro · Relay Modules · REST API

── PROJECT 4: STUDENT PORTAL SYSTEM ───────────────

Tagline: "Academic management, clean and efficient."

A responsive, Django-powered student portal system with authentication, academic dashboards, student data management, and a clean modern UI — built for real institutional use.

This Django-based full-stack application provides educational institutions with a clean, organized system for managing student data and academic records. Built with a responsive frontend using HTML, CSS, and JavaScript, it adapts seamlessly to both desktop and mobile browsers.

The system includes a secure authentication system, role management, and an academic dashboard where students can view their records, and administrators can manage student data efficiently.

• Responsive UI — Works flawlessly on desktop, tablet, and mobile
