── 14. PROJECT: SMART HOME AUTOMATION SYSTEM ────────────────

Tagline: "Your home, intelligent and in your control."

One-liner:
IoT home automation system using ESP32, Arduino, and Sinric Pro — with relay control, real-time mobile app integration, and voice assistant support.

Short:
A full IoT smart home automation system that bridges mobile software with real-world hardware. The ESP32 microcontroller controls home appliances via relay modules, while Sinric Pro enables voice assistant integration with Amazon Alexa and Google Assistant. A Flutter mobile app provides a clean remote control interface with real-time device status, scheduling, and automation rules — making any home smart and affordable.

Full:
This project started with a simple question: can we make home automation genuinely affordable and DIY-friendly without sacrificing capability?

The answer was yes. Built around the ESP32 microcontroller, this system controls physical appliances via relay modules over a home WiFi network. No expensive hubs required. Sinric Pro acts as the cloud bridge, enabling full Amazon Alexa and Google Assistant voice command support. The Flutter mobile app provides a real-time control panel — toggle any device, check live status, and set automation schedules from anywhere.

The Python firmware running on the ESP32 handles low-latency relay switching and maintains a persistent MQTT connection for real-time communication. The entire system is designed to be modular and extensible — add more relays, sensors, or automation rules without rearchitecting anything.

Features:
• IoT Device Control — ESP32-powered relay switching for home appliances
• Flutter Mobile App — Clean, real-time remote control interface
• Voice Assistant — Amazon Alexa & Google Assistant via Sinric Pro
• Real-Time Status — Live device state monitoring in the app
• Scheduling — Set timers and automation rules
• WiFi Control — Direct WiFi, no hub required
• Extensible Architecture — Add devices and sensors modularly

Tech Stack: Python · ESP32 · Arduino · Sinric Pro · Relay Modules · Flutter · MQTT · REST API
Hardware: ESP32, 4/8-Channel Relay Module, Power Supply

## 🚀 Getting Started

### Prerequisites
- Flutter SDK >= 3.x
- Dart >= 3.x
- Firebase project configured
- Android Studio / VS Code

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/iliyazdev/[repo-name]

# 2. Navigate to project
cd [repo-name]

# 3. Install dependencies
flutter pub get

# 4. Configure Firebase
# Add google-services.json (Android) and GoogleService-Info.plist (iOS)

# 5. Run the app
flutter run
```
